## 冷加载与计时解释

本次首次文本编码器加载约 1894 秒，首次磁盘卸载编码约 1100 秒，首次解码器加载约 328 秒。这些阶段受当前 NAS 读取与卸载影响，不能当作纯 GPU 推理耗时。后续请求复用组件和文本特征。

首次新 prompt 的完整生成约 3594 秒，包含上述加载；参考路径复用文本缓存，不能直接用两者总耗时计算加速比。CUDA Event 跨越 CPU 读盘等待时也包含时间间隔，不能理解为 GPU 全程忙碌。最终版将 pread 作用域覆盖卸载编码读取；其数值等价由独立 CPU/CUDA 测试验证，没有重复整段冷编码计时。

## 未覆盖能力

不同 GPU/驱动/编译器组合、NPU、多卡、训练、LoRA、参考条件工作流、任意时间表、HTTP 服务和自动进程恢复均不在本轮验证范围。可通过输入检查的形状也不代表所有组合都已做视觉质量评估。

本轮主要目标是完整流程与正确性，没有进行新的平衡性能实验，不发布新的加速比结论。
